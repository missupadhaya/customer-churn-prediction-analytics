# 📊 Customer Churn Prediction & Analytics

## 📌 Project Overview

Customer Churn Prediction is a Machine Learning project designed to analyze customer data and predict whether a customer is likely to leave a service.

The project uses customer information, behavioral patterns, and service-related attributes to identify potential churn customers. It helps businesses understand customer retention and make data-driven decisions to improve customer satisfaction.

## 🎯 Objectives

- Predict customer churn using Machine Learning.
- Analyze customer behavior and retention patterns.
- Identify factors contributing to customer churn.
- Visualize customer data and churn insights.
- Support data-driven customer retention strategies.

## 🤖 Machine Learning

The project uses Machine Learning techniques to analyze customer characteristics and predict churn.

The model learns patterns from customer data to classify customers into:

- **Churn** – Customers likely to leave the service
- **Not Churn** – Customers likely to continue using the service

## 📈 Evaluation Metrics

Model performance is evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC

## ▶️ How to Run the Project

Clone the repository:

```bash
git clone https://github.com/missupadhaya/customer-churn-prediction-analytics.git
```

Navigate to the project folder:

```bash
cd customer-churn-prediction-analytics
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
